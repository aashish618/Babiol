# Babiol - On-Demand Baby Care in 10 Minutes

Babiol is an innovative on-demand baby care service that connects busy parents with verified, professional babysitters in just 10 minutes. Operating in Hyderabad and Bangalore, we're transforming how parents get reliable childcare for short durations (1-3 hours).

## 🎯 About Babiol

**The Problem:**
- Parents struggle to find trusted, immediate baby care
- Hiring babysitters traditionally requires weeks of planning and vetting
- Parents rarely get personal time without extensive coordination

**Our Solution:**
- Get verified babysitters at your doorstep in 10 minutes
- Book for 1-3 hour slots based on your needs
- All caregivers are thoroughly background-checked and trained
- Real-time tracking and professional service
- Reclaim your personal time instantly

## 🚀 Features

- **Lightning-Fast Delivery**: 10-minute caretaker arrival
- **100% Verified**: All caregivers undergo thorough background checks
- **Flexible Booking**: 1, 2, or 3-hour time slots
- **Trusted Professionals**: Expert caregivers trained in child safety
- **Parent Community**: Connect with other parents
- **Growing Coverage**: Currently in Hyderabad & Bangalore

## 📱 Technology Stack

- **Frontend**: Next.js 15 with React 19
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Package Manager**: npm

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/aashish618/Babiol.git
cd Babiol

# Install dependencies
npm install

# Run development server
npm run dev
```

The application will be available at `http://localhost:3000`

### Build for Production

```bash
npm run build
npm run start
```
